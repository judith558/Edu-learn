HTML Basics

1. Page Structure

HTML (HyperText Markup Language) gives a web page its structure. It uses tags such as <h1> and <p> to tell the browser what each piece of content is.

  • <!DOCTYPE html> tells the browser this is an HTML5 page.
  • <head> holds information about the page, like its title.
  • <body> holds everything you see on the screen.
  • Most tags come in pairs: an opening tag <p> and a closing tag </p>.
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, World!</h1>
  <p>This is my first web page.</p>
  <a href="https://www.example.com">Visit a link</a>
  <img src="cat.jpg" alt="A cute cat">
  <ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
  </ul>
</body>
</html>

2. Forms & Inputs

Forms let users type and send information, like a sign-up or contact form. Each input should have a <label> so everyone knows what to type.

  • type="text", "email" and "password" create different text boxes.
  • type="radio" lets users pick one option; "checkbox" lets them pick many.
  • <select> creates a dropdown menu.
<form>
  <label for="name">Name:</label>
  <input type="text" id="name" placeholder="Your name">

  <label for="email">Email:</label>
  <input type="email" id="email" required>

  <label for="course">Course:</label>
  <select id="course">
    <option>HTML</option>
    <option>CSS</option>
    <option>JavaScript</option>
  </select>

  <button type="submit">Sign Up</button>
</form>

CSS Basics

3. Selectors & Colors

CSS (Cascading Style Sheets) controls how HTML looks: colors, fonts, sizes and spacing. A CSS rule has a selector (what to style) and declarations (how to style it).

  • p selects every paragraph (tag selector).
  • .card selects elements with class="card".
  • #header selects the element with id="header".
/* Tag selector */
body {
  font-family: Arial, sans-serif;
  background-color: #f8fafc;
}

/* Class selector */
.card {
  color: #1e293b;
  font-size: 18px;
}

/* ID selector */
#header {
  background-color: #4f46e5;
  color: white;
  text-align: center;
}

/* Link it in your HTML head: */
/* <link rel="stylesheet" href="style.css"> */

4. Box Model & Flexbox

Every element is a box made of content, padding (space inside the border), border and margin (space outside the border). Flexbox makes it easy to line boxes up in rows or columns.

/* The box model */
.box {
  width: 200px;
  padding: 20px;          /* inside space */
  border: 2px solid #4f46e5;
  margin: 10px;           /* outside space */
}

/* Flexbox: put items side by side */
.container {
  display: flex;
  justify-content: space-between; /* horizontal */
  align-items: center;            /* vertical */
  gap: 16px;
}

/* Responsive: stack items on small screens */
@media (max-width: 600px) {
  .container {
    flex-direction: column;
  }
}

JavaScript Basics

5. Variables & Functions

JavaScript makes web pages interactive. Variables store data and functions are reusable blocks of code.

  • let creates a variable you can change; const creates one you can't.
  • Common data types: strings ("text"), numbers (42), booleans (true/false) and arrays ([1, 2, 3]).
  • if statements make decisions, and loops repeat code.
// Variables
let studentName = "Ada";
const passMark = 50;
let score = 75;

// Function
function checkResult(name, score) {
  if (score >= passMark) {
    return name + " passed with " + score + "%!";
  } else {
    return name + " needs more practice.";
  }
}

console.log(checkResult(studentName, score));

// Loop through an array
const topics = ["HTML", "CSS", "JavaScript"];
for (let i = 0; i < topics.length; i++) {
  console.log("Learning " + topics[i]);
}

6. The DOM & Events

The DOM (Document Object Model) is how JavaScript sees your HTML page. You can select elements, change their text or style, and react to events like clicks.

<!-- HTML -->
<h2 id="message">Hello!</h2>
<button id="changeBtn">Click me</button>

<script>
  // Select elements
  const message = document.getElementById("message");
  const button = document.getElementById("changeBtn");

  // React to a click
  button.addEventListener("click", function () {
    message.textContent = "You clicked the button!";
    message.style.color = "#4f46e5";
  });
</script>
